# Lunara — privacy policy

The published privacy policy for **Lunara**, an Android menstrual cycle tracker that keeps everything on the phone: no account, no server, no analytics.

It lives in its own repository because a privacy policy has to be reachable at a stable public URL — Google Play requires one — while the application source does not need to be public. Nothing else from the project is here.

**Published at:** https://unupunct.github.io/lunara-privacy/

The document is in Romanian, the language of the app. The canonical copy is `docs/PRIVACY.md` in the application repository; this is a mirror kept in step with each release.
